# PROTOTYP — erbjudandets datakontrakt

Frågan är om ett gemensamt, källspårat datakontrakt kan representera både köp och leasing och samtidigt förklara varför en annons är preliminär, verifierad, rankningsbar, reserverad eller utgången. Prototypen provar statusövergångar, verifieringsbevis, prisändringar och engångsarkivering av bilder i minnet. Den är inte produktionskod och sparar ingenting.

Kör från `bilradarn-report`:

```powershell
npm run prototype:contract
```

Skriv en bokstav och Enter för att förändra posten. Hela relevanta tillståndet ritas om efter varje åtgärd.
