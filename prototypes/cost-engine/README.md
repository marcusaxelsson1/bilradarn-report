# PROTOTYP — kalkylmotor

Frågan är om Bilradarn kan redovisa samma 36-månadersutfall som både ekonomisk kostnad och faktiskt prognostiserat kassaflöde utan att dubbelräkna amortering, restvärde, deposition, däck eller riskreserver. Prototypen visar separata köp- och leasingalternativ, grund/stress, extra mil samt en fristående åttaårig köpbilprognos.

Kör från `bilradarn-report`:

```powershell
npm run prototype:cost
```

Prototypen sparar ingenting och använder endast markerade exempelvärden.
